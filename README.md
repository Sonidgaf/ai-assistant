# AI-маркетолог (Telegram-бот)

Каркас MVP: анкета при старте, 6 сценариев с кнопками-примерами, короткие ответы-карточки с кнопками «📖 Подробнее» и «🔄 Другой вариант», память диалога внутри сценария, бесплатный лимит запросов, /stats для админа.

## Запуск локально

Нужен Python 3.12 или 3.13 (на 3.15 часть библиотек пока не ставится). На Windows вместо `python` используйте `py -3.13`.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и LLM_API_KEY
python -m bot
```

## Команды бота
- /start — анкета или главное меню
- /profile — заново заполнить анкету
- /stats — число пользователей (только для ADMIN_IDS)

## Свежесть данных и конкуренты
- Модель получает сегодняшнюю дату и опирается на данные за последние 4–6 месяцев.
- `WEB_SEARCH=true` включает поиск в интернете через OpenRouter (около 0.02 $ за запрос). В ответах появляются ссылки на источники.
- В «Анализе конкурентов» бот сам читает публичные Telegram-каналы (t.me/…, @канал), сайты и VK-сообщества (нужен `VK_TOKEN`) и учитывает только посты за последние 6 месяцев.

Проверки: `python tests/smoke_test.py` и `python tests/competitors_test.py`.
